# KEPLER V 辅助控制模块 V1 PCB 与制造检查

[项目主页](../README.md) | [English README](../README.md) | [中文 README](../README.zh-CN.md)

本文记录 V1 PCB 的尺寸选择、层叠、接口、布线、检查结果和下单前限制。它的用途是让重新制作这块板的人知道哪些地方已经检查过，哪些 warning 仍然存在。

## 板级摘要

| 项目 | V1 |
|---|---|
| 板框 | 25.000 mm × 26.016 mm |
| 层数 | 4 |
| 板厚 | 1.6 mm |
| 器件数量 | 36 |
| 走线段数 | 501 |
| 过孔 | 47 |
| 覆铜 | GND 和 +3V3 各一层 |
| 原生 DRC | 0 violation |
| 扩展 DFM | 0 error，64 warning |

当前原生项目归档位于 [source/easyeda/kepler-v-acm-v1.epro2](../source/easyeda/kepler-v-acm-v1.epro2)。Gerber、BOM、CPL、DRC/DFM 原始 JSON 和铜层快照属于本地生成物，保存在 `outputs/`，不提交到公开仓库。

## 尺寸选择

最初目标是 20 mm × 20 mm。按现有 USB-C、SWIO、飞控串口、两组舵机、GPIO 和录像接口排布后，这个尺寸会压缩焊盘间距和丝印空间，不利于手焊。

V1 最终采用 25.000 mm × 26.016 mm。它比方形目标多出 1.016 mm 高度，仍低于 30 mm × 30 mm 的上限。这个尺寸不是布局失误导致的失控扩张，而是在连接器、焊线间距和可维护性之间做出的取舍。

## 层叠

| 层 | 用途 |
|---|---|
| Top | 主要器件、USB、焊线接口和顶层走线 |
| Inner1 | GND 正片覆铜 |
| Inner2 | +3V3 正片覆铜 |
| Bottom | CH32、CH340、74HC4053 和背面走线 |

EasyEDA 把两个内层报告为 `SIGNAL`，实际都按网络铺了完整铜面。设计曾尝试把 Inner1 改为负片 `PLANE`，宿主接口没有完成写入。V1 保留可回读的正片覆铜方案，避免把无法验证的状态写进发布文件。

这块板的负载电流不大。GND 和 +3V3 的完整内层已经能覆盖逻辑供电需求。舵机和录像负载不经过本板 3.3 V 稳压器。

## 外部接口

原理图用 J1 到 J6 表示接口，PCB 使用对应的 2.54 mm 通孔焊盘。生产时直接焊线，不安装排针，也不把 J1 到 J6 放进贴片 BOM。

每个 J1 到 J6 焊盘都在顶层丝印标了短网名。左侧接口朝板内向右标，右侧接口向左标，底部接口朝板上标，避免文字压到对应焊盘或跑出板框。

| 接口 | 网络 |
|---|---|
| J1 | `FC_5V / GND / FC_UART5_TX / FC_UART5_RX` |
| J2 | `SERVO1_PWM / GND` |
| J3 | `SERVO2_PWM / GND` |
| J4 | `GPIO1 / GPIO2 / GPIO3 / GND` |
| J5 | `DVR_AVI_N / DVR_JPG_N / GND` |
| J6 | `+3V3 / GND / SWIO / NRST` |
| J7 | USB-C，连接 CH340N 和 USBLC6 |

## 布线与电源

UART 切换、USB、SWIO、录像触发、舵机 PWM 和 GPIO 都已经连到对应焊盘。GND 使用 Inner1 完整覆铜，+3V3 使用 Inner2 完整覆铜。能安全加缝合孔的位置已经补孔，靠近定位槽和窄焊盘的位置没有强行打孔。

`+5V_AUX` 使用 10 mil 以上走线，没有单独分配内层。对当前逻辑负载够用，但如果后续版本增加大电流外设，应重新评估线宽和铜面。

USB 是 CH340N 的 Full-Speed 接口，不是 High-Speed。板内 D+/D- 路径很短，并按相邻和短路径布线。V1 没有引入 High-Speed 的阻抗与等长要求。

USB-C 定位槽到铜走线的最小规则为 8 mil，对应 0.2032 mm。普通铜间距仍为 6 mil。下单前必须在板厂预览中确认定位槽不会被放大、补铜或改变形状。

## USB/UART 切换的板级检查

74HC4053 的两路选择端并联到 `USB_SEL`，逻辑电源为 3.3 V。R14 使用 68 kΩ，R15 使用 100 kΩ，用来提高 USB 插入时的选择电平余量。

检查范围包括：

- 插入 USB 时选择高电平，MCU UART 接 CH340。
- 拔出 USB 时选择低电平，MCU UART 回飞控。
- PD3 只连接分压节点，没有输出驱动。
- CH340 的 VCC 和 V3 都接 3.3 V。
- USB D+/D- 经过 USBLC6，连接顺序与芯片引脚一致。

电源和信号检查通过。完整的上电时序仍应在实物上验证，尤其是 USB 热插拔和 MCU 复位同时发生时。

## 检查结果

原生 PCB DRC 返回 0 violation，扩展 DFM 返回 0 error 和 64 warning。检查还确认了 0 短路、0 桥接、0 孤立线，以及没有焊盘内过孔或单层过孔。

这些结果覆盖网络、铜几何、规则检查和保存后的回读。它们不覆盖实物焊接、USB 眼图、EMC、热循环和飞行振动。

### 64 个 DFM warning

这些 warning 不阻塞生产，但下单前应逐项看：

- 23 个小器件位号与焊盘包围盒相交。它们主要影响装配图可读性。
- C1 距 LDO 输入脚约 315 mil。
- C6 和 C7 距 MCU 电源脚约 135 mil 和 222 mil。
- 19 组局部并行线低于 3W 启发式阈值。
- 8 条走线不是理想的 0°、45° 或 90° 方向，4 个折角小于 90°。
- `+5V_AUX` 的主要部分仍以 10 mil 走线为主。
- USB-C 的 4 个多边形电源和屏蔽焊盘无法由几何检查完整证明连接路径。

这些问题属于下一版布局优化范围。V1 没有把它们写成已修复，也没有通过修改检查规则隐藏它们。

## 制造建议

1. 从 EasyEDA 重新导出 Gerber、BOM、CPL 和钻孔文件。
2. 检查四层铜、GND/3V3 覆铜、板框、丝印、阻焊和 USB-C 定位槽。
3. 确认 J1 到 J6 不在贴片 CPL 中。
4. 检查有铅喷锡、板厚 1.6 mm 和四层结构是否与订单一致。
5. 使用板厂 DFM 预览处理位号压焊盘和细小间距 warning。
6. 首次生产建议先做 5 片，不直接批量下单。

## 实物验收

板子到货后先检查电源对地短路。再用限流电源从 `FC_5V` 供电，确认 3.3 V 输出和待机电流。USB 插入、拔出时测量 `USB_SEL` 和 UART 路径，随后测试 SWIO、CH340、PWM、GPIO 和录像触发。

舵机和录像模块应在卸桨状态下逐个接入。最后拔掉飞控 UART，确认超时后所有输出进入定义的安全状态。
